# ItemsTable — таблица баланса предметов

Одностраничный HTML, две вкладки.

**Предметы** — все предметы мода: иконка из игры, исходный файл и строка,
вариант (DIY / Buyable), цена покупки, рецепт крафта, выхлоп разбора и лимит
установки.

**Таланты** — что каждый талант открывает и сколько разрешает ставить: сводная
таблица групп `BIBA*` и карточки всех восьми талантов.

Все поля правятся прямо на странице, кнопка «Экспорт диффа» отдаёт JSON только
с тем, что изменилось.

## Про лимит установки

`CharacterAbilityGivePermanentStat` без `setvalue` **прибавляет** значение к
накопленному (`CharacterInfo.cs:2157`). Каждая книга мода дублирует
перекрытый ванильный талант один в один, поэтому персонаж с обоими получает
двойной лимит: механик с `modularrepairs`, прочитавший «DIY: Mechanics»,
ставит 6 малых помп вместо 3. Столбец «итого» в таблице групп считает эту
сумму, а не то, что написано в описаниях талантов.

## Пересборка

```
python Tools/ItemsTable/extract.py      # Xml/ + собранный мод + ваниль -> items.json
python Tools/ItemsTable/build_page.py   # items.json + шаблон -> riba-items.html
```

`build_page.py` принимает необязательный аргумент — путь для готовой страницы.

## Откуда что берётся

| Данные | Источник |
|---|---|
| цена, рецепт, разбор, спрайты | **собранный** мод в `<игра>/LocalMods/RIBA Portable Items/Xml/` |
| файл и номер строки | исходники `Xml/Items*.xml` (lxml, `sourceline`) |
| названия и описания | `Localization/English*.xml`, `Russian*.xml` |
| иконки компонентов | `<игра>/Content/Items/**/*.xml` + текстуры игры |
| рецепты и лимиты талантов | `Xml/Talents.xml` — `AddedRecipe`, `CharacterAbilityGivePermanentStat` |
| состав групп `BIBA*` | `Lua/data.json`, таблица `Bibs` |
| работа и тир перекрытых талантов | `<игра>/Content/Talents/TalentTrees.xml` |

Значения берутся из **сборки**, а не из исходников, потому что `ImportItem`
наследует ванильные блоки: у `RIBATerminal` и `RIBABuyableTerminal` `Fabricate`
в `Xml/` вообще нет, он приезжает от ванильного `terminal`. Поэтому перед
пересборкой таблицы имеет смысл прогнать `build.cmd` — иначе цифры будут от
предыдущей сборки.

Из-за этого же в таблице нет `RIBAMover`: `Xml/Items5.xml` не значится в
`RIBAfilelist.xml`, то есть в собранный мод не попадает.

## Пути

`extract.py` держит их константами вверху файла: `SRC` (эта репа), `BUILD`
(собранный мод в LocalMods), `GAME` (папка игры). Переехала игра — правь там.
